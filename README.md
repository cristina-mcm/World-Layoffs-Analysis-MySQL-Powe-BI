# World-Layoffs-Analysis-MySQL

Project Overview
This MySQL project cleans and explores a global layoffs dataset covering 2020–2023. The analysis examines reported layoffs by company, industry, country, company stage, and time period.

This was completed as a guided project based on Alex The Analyst's Data Analyst Bootcamp, with additional comments and documentation added for clarity.
